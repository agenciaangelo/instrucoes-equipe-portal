Fluxo

O que acontece quando
você move um card

Cada movimentação no Trello dispara uma atualização automática no portal.

1
Card entra em Briefing
Status da demanda no portal atualiza para "Briefing". O cliente vê que a demanda foi recebida.
Cliente vê ✅
2
Card avança para produção
Cada coluna que o card passa atualiza o status no portal em tempo real. Cliente acompanha sem perguntar.
Automático ✅
3
Card chega em Aguardando aprovação
Cliente recebe notificação no sininho do portal. Pode ver os comentários que o admin liberar.
Notificação automática ✅
4
Card vai para Concluído
Cliente recebe notificação de conclusão. A demanda continua visível na coluna Concluído do kanban.
Notificação automática ✅
5
Card arquivado no Trello
Demanda some do portal automaticamente — mas fica salva no histórico do Sheets.
Arquivamento automático ✅
Transparência

O que o cliente vê
e o que não vê

👁️
Vê — Status da demanda em tempo real
O cliente acompanha em qual etapa a demanda está — Briefing, Em andamento, Aguardando aprovação, Concluído.
💬
Vê — Comentários liberados pelo admin
Quando a demanda está em Aguardando aprovação ou Concluído, o admin pode liberar comentários específicos do Trello para o cliente ver.
📝
Vê somente em Briefing — Descrição da demanda
A descrição só fica visível enquanto a demanda está em Briefing. Nas demais etapas fica oculta.
🔒
Não vê — Comentários não liberados
Comentários internos da equipe no Trello ficam ocultos. Só aparecem para o cliente após liberação manual do admin.
✏️
Não pode editar — Após sair do Briefing
O cliente só pode editar a demanda enquanto ela está em Briefing. Após avançar, o conteúdo fica bloqueado.

Atenção

O que não fazer
no Trello

🚫
Não renomear as listas do Trello
Os nomes das colunas são mapeados pelo portal. Renomear quebra a sincronização e a demanda some do kanban.
🚫
Não juntar duas demandas em um único card
Cada demanda deve ter seu próprio card. Errado: "[Floema] Vídeo Dia das Mães + Campanha de Maio". Certo: dois cards separados, um para cada entrega.
📎
Entregáveis vão nos comentários do card
Cole o link do Drive no comentário do card. Se houver mais de uma versão, identifique claramente:

v1 → https://drive.google.com/...
v2 → https://drive.google.com/...
🔗
Sempre subir o arquivo no Drive antes de mover para Aguardando aprovação
O cliente espera o link no comentário. Cole o link e só então mova o card para a próxima etapa.
🚫
Não copiar cards — sempre criar um novo
Cards copiados no Trello não são reconhecidos pelo portal. O sistema só detecta criações novas. Para uma nova demanda, sempre crie um card do zero.
